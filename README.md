# ArAI

Understanding transformers from the base up.

Not a tutorial repo, and not a "build a GPT in 100 lines" repo. The goal is to
understand *why* every piece of a language model is the way it is — why matrices,
why calculus, why attention — and only then write the code, because by that point
the code is the easy part.

- `notes/` — the actual point of this repo. The reasoning, in order.
- `data/` — training corpus (tinyshakespeare, ~1.1MB of characters).
- code — arrives once the math it implements is already understood.
